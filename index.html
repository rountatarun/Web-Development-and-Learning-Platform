Text & Formatting

Learn headings, paragraphs, bold, italic and other text elements.

CSS

Learn CSS

Make your websites beautiful, responsive and professional.

CSS Basics

Learn selectors, properties and values.


h1 {
    font-size: 40px;
}

Colors & Text

Learn colors, fonts, text alignment and spacing.


p {
    font-size: 18px;
    line-height: 1.6;
}

Box Model

Learn margin, border, padding and content.


.box {
    padding: 20px;
    margin: 10px;
}

Flexbox

Learn modern one-dimensional layouts.


.container {
    display: flex;
    gap: 20px;
}

Grid

Learn powerful two-dimensional layouts.


.container {
    display: grid;
    grid-template-columns:
    repeat(3, 1fr);
}

Responsive Design

Make websites work on mobile, tablet and desktop.


@media (max-width: 768px) {

    .container {
        width: 100%;
    }

}

JavaScript

Learn JavaScript

Add logic and interactivity to your websites.

Variables

Store data using variables.


let name = "Tarun";

const age = 18;

Conditions

Make decisions using if and else.


if (age >= 18) {
    console.log("Adult");
}

Loops

Repeat code using loops.


for (let i = 1; i <= 5; i++) {
    console.log(i);
}

Functions

Create reusable blocks of code.


function greet() {
    console.log("Hello");
}

DOM

Change webpage elements using JavaScript.


document.querySelector("h1");

Events

Respond to user actions.


button.addEventListener(
    "click",
    function() {
        alert("Hello");
    }
);
